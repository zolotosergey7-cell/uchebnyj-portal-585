# Учебный портал 585 GOLD

Временный портал для новых сотрудников: регистрация, траектория из 10 SCORM-курсов в 3 этапа, результаты в Google Таблицу.

- `index.html` — главная (регистрация, траектория)
- `player.html` — плеер SCORM 1.2
- `config.js` — список курсов, этапы и адрес Google Apps Script (`api`)
- `apps-script/Code.gs` — код для Google Таблицы
- `courses/` — распакованные курсы
